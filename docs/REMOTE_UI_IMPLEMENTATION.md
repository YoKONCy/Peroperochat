# 远程客户端 UI 实装记录

基于 `docs/design/remote-client-prototype/` 的定稿，将布局、SVG 图标和角色 CG 迁入 Vue 正式页面。标准浅色沿用 Pero 的蓝白与缎带，标准暗色沿用 Nana 的紫色与星轨。普通应用文案由界面提供，角色姓名、头像、描述、心情和实际回复来自远程数据；原型中的旅行消息和文件示例未带入生产页面。

## 入口和页面

2026-10-21 起开放独立模式房间菜单 → **infOS 客户端**，设置总览也提供「运行模式与远程连接」。连接页支持设备配对、管理凭据登录、兼容 Bearer、重新授权和返回独立空间。独立模式正在回复或仍有未发送草稿时，先处理当前内容再切换，避免默默丢弃草稿。

连接面板分开显示保存当前空间、核对设备授权、切换运行模式的进度；连接已保存但进入失败时保留连接卡，不要求再次兑换配对码。原生关闭旧模式后，统一过渡页显示交接及恢复；失败时可重试当前目标，或明确返回独立空间。独立页面等角色与显示偏好恢复后再挂载，远程离线与授权失效不会自动启用独立模式。

模式切换使用星笺、缎带、月牙与星屑的内联 SVG＋CSS 动画。首次绘制后至少展示 2 秒；原生交接、角色与主题读取、上次会话恢复仍在进行时继续播放，完成后淡出。新页面可以在遮罩下恢复，但暂时不可交互；时长限制只作用于展示，不延迟原生运行权切换。普通断线重连不弹出此全屏动画，继续使用原来的连接状态条。

正常过渡只显示目标空间、一句轻文案和随机 TIPS。每次进入随机选择，等待较久时每 6 秒更换且不连续重复；没有额外网络请求。恢复失败后停止漂浮动画并保留重试、返回独立空间及数据恢复入口。过渡页提供焦点约束、深浅系统配色和系统减少动效支持，不使用 emoji 图标。

底栏为首页、会话、任务、资料、管理。配置、资料写入、据点和工作台集中在管理页，详见 [管理与工作台接入记录](REMOTE_MANAGEMENT_IMPLEMENTATION.md)。通知与审批从页头铃铛或首页通知入口进入。启动保留上次会话恢复，首页通过底栏主动打开。会话大图保持收起，通过页头按钮单独查看。

| 管理与工作台 | 配置、角色、模型、提示词与技能；资料写入、据点与调度；文件编辑、终端与会话引用；设备、实例、统计和维护 |

| 本机角色外观 | 内置 Pero/Nana CG、自定义角色选择本机 CG、恢复默认、导入或移除 JSON 样式包、导出制作模板 |

## 组件与主题

- `RemoteWorkspace.vue` 保留既有会话传输、草稿恢复、模式令牌和未决请求逻辑，并编排五栏页面。
- `RemoteHome.vue`、`RemoteAppearance.vue`、`RemoteFileCover.vue` 为可复用展示组件。
- `RemoteIcon.vue` 仅渲染 `remoteArtwork.js` 内受信任的矢量常量，不接受远程 SVG 源码。
- `remote-theme.css` 为定稿主题层，限定在 `.remote-themed` 容器。`RoomDrawer` 通过注入获得同一主题，Teleport 后弹层仍保持一致。
- 主题不通过全局独立模式角色 ID 或独立 Store 推导。CG 只在服务端角色 ID 明确匹配 `pero`／`nana` 时使用内置素材；其他角色默认头像，可选择自己的 CG。
- 系统和应用内减少动效设置均生效。

## 原生持久化

沿用 `data/remote/{profileId}/client.sqlite`，不会存入独立模式数据库或浏览器 localStorage。

- 新增 `{ kind: 'appearance' }`：连接级明暗、配色、CG 展示、减少动效、角色样式开关。
- 扩展 `{ kind: 'character', agentId }`：兼容旧的 expanded、model、palette；新增本机 CG 和样式配置。
- 旧角色偏好缺少新字段时使用默认值；不会破坏原会话草稿与阅读位置。
- 持久化仍通过原生运行令牌、连接分区、事务、数量与总容量限制。界面保存失败提供可见错误，不跨连接自动重写。

## 角色样式包

在角色的显示偏好中导出模板，再导入 JSON。支持的格式：

```json
{
  "schemaVersion": 1,
  "style": {
    "name": "我的角色样式",
    "lightAccent": "#467fc5",
    "darkAccent": "#c2a7ef",
    "secondary": "#d79bb8",
    "bubble": "ribbon",
    "decoration": "constellation"
  }
}
```

颜色可选，必须为六位十六进制颜色。`bubble` 为 `standard`、`ribbon`、`soft`；`decoration` 为 `standard`、`ribbon`、`constellation`、`none`。未覆盖部分继承标准主题。文件上限 32 KiB，Rust 再次校验字段和枚举，拒绝任意 CSS／脚本／资源 URL。

本机 CG 支持 PNG、JPEG、WebP，上限 2 MiB，按角色保存到当前连接的原生偏好中；原生限制媒体前缀、编码字符与大小，不接受 SVG、HTML 或远程 URL。CG 与样式属于本机展示偏好，不改写服务端人设、不上传到会话，也不与其他客户端同步。

## 验证与边界

### 工具调用与思考展示补充（2026-10-20）

对照 infOS 当前官方工具 manifest、工具用户名称、工具执行结果处理器和 Surface 投影优化正式客户端。原型中的行程、天气和方案数字仍是示意数据，没有迁入正式页面。

- 新增受限只读查询 `tools`，对应 `/agents/tools?includeAdvanced=true`。当前连接的服务端 `display` 名称与样式优先，离线或接口不可用时使用 97 项官方工具的展示兜底；未知扩展仍可展开查看完整调用。此清单只用于展示，不代表工具已获执行授权。
- 按同一 Surface 内唯一的 `callId` 合并调用与返回结果。重复身份、孤立结果均保留，不跨会话或 Surface 猜测关联。
- NIT 内部工具按服务端 `parentCallId` 收纳到对应 `run_script` 卡片，按原始调用开始顺序排列，各子调用独立折叠，父卡收起可整体折叠。父卡显示已收到的内部调用数量及服务端状态分布，不把这些数量作为整个脚本的业务进度。子调用失败在摘要中优先提示，父级执行状态仍单独取服务端记录。脚本参数与外层返回放在次级详情中，内部工具列表优先展示。
- 分组仅接受同一 Surface 内唯一、明确的脚本父级和子调用身份；父级缺失、重复、循环或嵌套脚本等异常关系平铺保留并提示，不根据 `nit-` 前缀或相邻位置猜测。未记录子调用的旧数据不会伪造内部步骤。调用详情在首次展开后挂载，整体收起时保留已展开的子卡状态。
- 文件、检索、终端、网页、浏览器、桌面、视觉、提醒、计划、技能、记忆、社交和据点使用类别图标、目标字段及状态展示。服务端 SVG、任意 CSS 和脚本不会进入渲染器。
- 搜索结果只按已识别的文件搜索结构显示数量与前六项位置；不把任意数组解释为文件总数。终端退出码、事件查询数量及提醒时间仅在实际结果包含相应字段时显示。未识别的结果保留原文。
- 工具错误摘要、耗时和自动审批结论可查看。事件记忆的 `accepted` 草稿明确标注“随回复保存后提交”，不当成已经持久化。
- 参数和结果默认仅渲染前 6000 字符，可以手动展开；本机截断和服务端截断分别提示。参数接收完成后优先展示正式 `args`，不会继续使用旧的流式预览。
- 思考区保留服务端顺序，显示轮次、耗时、接收状态；接收中断后不再标成正在接收。新增 `model-retry` 重试记录展示。
- 首页任务使用真实 `currentStage`；任务详情和行动清单展示真实计划步骤。更新计划工具还可以按需读取“当前行动清单”，明确区分当前计划和历史工具结果。步骤比例不作为产出验收状态，也不使用工具调用次数推算完成度。
- 修复任务 `progress` 的取值范围：infOS 当前返回 0–100，未知或越界值不画百分比。
