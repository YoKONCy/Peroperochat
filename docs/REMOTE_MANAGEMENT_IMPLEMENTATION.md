# 远程管理与工作台接入记录

本轮对照当前 infOS 服务端路由补齐手机入口，入口为远程模式底栏 **管理**。会话页右上角的操作菜单可直接打开会话设置和工作台；资料页也提供管理入口。沿用现有浅色、暗色和角色主题，不加入子应用页面或内置浏览器。

## 职责与隔离

- `src-tauri/src/remote/management.rs` 按固定操作名映射方法、路径与查询条件，复用原生凭据、实例身份核验和运行代次校验；不提供任意 HTTP 代理。
- `remote_manage` 读取直接返回，不进入投影缓存。写入登记仍复用持久待核对机制，但只保存操作名、对象标识与请求指纹，不保存配置正文或成功回执中的密钥/配对码。
- 配置、提示词与资料的业务校验、权限、发布、持久化和执行继续由 infOS 处理。手机只保留编辑态，离开对应页面释放；独立模式的 Store、数据库与工具不参与这些操作。
- 写请求不自动重试。网络中断后的未知结果可从原有核对抽屉处理，确认结果前阻止再次提交。对重置和删除等操作提供明确确认。
- 文件保存发送 `expectedHash`，消息编辑发送 `expectedRevision`；服务端冲突不会由客户端强行覆盖。范围截断的文件只读，避免把片段覆盖为完整文件。
- 工作台文件和终端可以显式带入当前对话，沿用服务端 `workspaceContext` 字段。引用随草稿按连接/角色/会话持久化，并在确认入队后清空；断线未确认时保留，不自动重发，也不把其他会话的引用带入当前会话。
- 管理表单、文件与提示词存在未保存修改时，切换底栏、会话或运行模式会被阻止；可保存，或从管理页返回并明确放弃。终端与群聊轮询只在对应组件存活、应用前台且连接在线时运行。

## 平台和显示边界

- 常规管理正文限制为 1 MiB，上传和普通响应沿用 8 MiB 上限。文本编辑一次最多读取 128000 字符，超出范围只读；文件原件另走原生流式保存，上限 2 GiB；PDF、Office、CSV 与 ZIP 的展示限制见 [远程文件说明](REMOTE_FILES.md)。
- 终端采用服务端游标轮询与有界文本输出，支持命令输入和控制，不是完整的 ANSI/TUI 终端模拟器。执行节点上的进程不因离开手机页面而自动结束。
- 群聊读取最近 100 条消息；历史记录页可分页读取普通会话，并导出当前页。会话设置支持有界的完整 JSON 记录导出，超过限制可分段保存，附件保留引用而不打包二进制内容；导出期间检测到记录变化会停止。大规模记忆关系图当前以结构化数据查看，未增加图形编辑器。
- 配置、提示词、角色包和历史导出在 Android 使用系统文档保存选择器，无需整盘存储权限；桌面写入下载目录的独立文件，避免覆盖已有文件。iOS 文本导出优先使用可用的系统 Web Share，原件下载保存到应用文档目录，供“文件”App 访问；移动平台实际行为尚未真机验证。
- 语音支持用户主动录音、上传音频识别和文字朗读。Android 声明录音权限并由 WebView 按需请求，iOS 增加麦克风用途说明。页面进入后台或销毁时停止录音，未实现手机后台常驻监听/唤醒。
- 浏览器工具仍可由远程 Agent 调用并展示结果；客户端没有新增内置网页浏览或子应用入口。
