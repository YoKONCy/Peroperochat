# 远程文件访问、预览与保存

## 入口与边界

沿用会话消息附件、资料页的工作区文件，以及管理工作台的文件预览入口。读取、预览和保存共用 `Resource` 白名单与 Rust 原生鉴权，不向页面提供服务端凭据，不接受任意 URL。工作区资源必须指定角色、会话、路径和版本；服务端仍负责执行节点的工作区边界。这里不提供任意服务器磁盘浏览或子应用、内置浏览器功能。

文件面板先通过鉴权 HEAD 读取 MIME、大小、原始文件名及 Range 能力，再选择预览方式。“保存原件”独立于预览，格式不受支持、预览失败或文件较大时仍可使用。

## 浏览界面

预览采用独立阅读面板：顶部保留文件封面、来源和大小，中间单独滚动，底部固定保存、进度、取消和结果。沿用角色浅色／暗色与配色包，以折纸 SVG、轻量玻璃工具栏和小过渡统一视觉；尊重系统与应用的减少动效设置。

工作台文件夹和资料页共用面包屑，工作台提供当前目录即时筛选并将文件夹排在前面。点击文件直接预览，文本编辑为单独操作；重命名、删除和未保存内容保护沿用原有流程。PDF 支持输入页码与适宽；图片提供缩放，文本可切换换行；Office 文档按章节／工作表切换，表格显示行列索引，ZIP 目录可按名字筛选。没有增加服务端写操作。

工作台和 ZIP 目录每次先显示 80 项，可逐步展开；切换文件夹时清空旧筛选，切换文档页码／章节时回到阅读区顶部，避免保留上一页的滚动位置。

本轮界面调整仅做源码审阅，没有运行前端测试、静态检查、构建、应用启动或视觉验收。

1.4.4 发布前已按新增授权运行 `pnpm test`，前端 **73 项通过**（包含全部 Vue 组件与模板的内存校验）。这不包含应用构建或真机视觉验收。

## 保存

- `remote_download_resource` 使用原生 HTTP 流逐块写入专用临时文件，不将文件转成 JSON 字节数组传给 WebView。单任务上限 2 GiB，不再受普通接口的 8 MiB 响应上限限制；同时允许一个下载任务。
- 界面显示进度和保存阶段，支持取消。模式切换会终止旧连接的下载；复制到目标文件时也检查旧模式是否失效。网络失败、取消、长度不符或保存失败不会显示成功，不自动重试或覆盖现有文件。
- 下载空闲超时 45 秒，总请求超时 30 分钟。已知长度会在接收前后校验，未知长度也持续检查上限；没有实现断点续传或应用退出后的持续下载。
- 临时文件按任务清理；异常退出的残留在下次初始化时清理。原件只在用户明确保存后进入导出位置，不进入会话投影缓存。
- Android 使用系统文档创建选择器，支持二进制文件，不申请整盘存储权限。后台线程以有界缓冲复制；JNI 运行门阻止已失效模式继续写入。取消、失败时尝试删除系统选择器创建的不完整目标；部分文档提供方可能拒绝删除，此时需在该提供方中清理。
- Windows 等桌面平台保存到下载目录，文件名添加唯一前缀，避免覆盖同名文件。iOS 保存到应用的“文稿/infOS导出”，通过“文件”App 查看；启用文档共享，业务数据继续保留在应用数据目录。
- 现有配置、角色包、提示词及会话 JSON 导出保持原有文本导出接口；不是二进制附件打包导出。

## 预览

| 格式 | 显示方式与限制 |
| --- | --- |
| 图片、音频、视频 | 沿用被动媒体控件；BMP 和 ICO 也加入图片类型。整文件预览上限 8 MiB，格式和编解码能力由设备决定；更大的文件可保存原件 |
| 文本、代码、JSON、XML、HTML、SVG | UTF-8 源码预览，最多前 256 KiB；大文本通过 Range 读取前缀，不整份装入内存。HTML 和 SVG 不注入 DOM、不执行 |
| PDF | 本地 PDF.js 引擎与字体资源，逐页画布、翻页、缩放、密码输入；优先使用鉴权原生 Range，关闭自动预取。文件最大 512 MiB，每次只绘制一页、画布最多约 400 万像素；不提供脚本、活动表单或链接执行 |
| DOCX | 正文文字速览，保留段落；不还原图片、样式、分页或复杂版面 |
| XLSX | 工作表及缓存单元格值；不计算公式、还原样式或日期格式，每表最多 200 行、30 列 |
| PPTX | 各页文字速览，不还原幻灯片布局、图片或动画 |
| CSV | 支持引号与换行的表格速览，最多 200 行、30 列 |
| ZIP | 目录与条目大小，最多显示 600 项，不解压到设备文件系统 |
| 其他格式、旧版 DOC/XLS/PPT、加密 Office、RAR/7z | 明确提示使用保存原件，不假装已经预览 |

Office 与 ZIP 的输入上限 8 MiB，解包在独立 Worker 中执行，超时会终止。扫描目录最多 10000 项；Office 最多提取 50 个正文分部，每个 XML 上限 2 MiB、累计上限 8 MiB。XML 拒绝 DTD/实体声明，显示只使用 Vue 文本与表格，不执行宏、外部引用或文档脚本。达到限制会提示截断或回退到保存原件。
