# 远程文件访问、预览与保存

## 入口与边界

沿用会话消息附件、资料页的工作区文件，以及管理工作台的文件预览入口。私有文件读取和保存共用 `Resource` 白名单与 Rust 原生鉴权，不向页面提供服务端凭据，不接受任意鉴权 URL 代理。直接工作区资源指定角色、会话、路径和版本；消息中的来源引用通过 infOS 解析，再使用当前会话的 `reference-content` 读取当前内容。服务端负责执行节点的工作区边界。这里不提供任意服务器磁盘浏览或子应用、内置浏览器功能。服务端解析出的公开外链不附带设备凭据；受浏览器跨域策略限制时使用系统打开。

文件面板先通过鉴权 HEAD 读取 MIME、大小、原始文件名及 Range 能力，再选择预览方式。“保存原件”独立于预览，格式不受支持、预览失败或文件较大时仍可使用。

## 浏览界面

预览采用独立阅读面板：顶部保留文件封面、来源和大小，中间单独滚动，底部固定保存、进度、取消和结果。沿用角色浅色／暗色与配色包，以折纸 SVG、轻量玻璃工具栏和小过渡统一视觉；尊重系统与应用的减少动效设置。

对话一期实装增加消息内媒体与文档小窗。图片／GIF 可原地查看并放大，音视频可原地加载播放并进入独立阅读面板。PDF 使用首页缩略，HTML／SVG 使用隔离缩略，MD 与 Office 使用正文／表格片段；点击小窗或标题进入完整阅读面板。流式 `send_file`、读图／截图返回及持久附件均接入同一入口，不必等到会话提交后才看到已返回的文件。

工作台文件夹和资料页共用面包屑，工作台提供当前目录即时筛选并将文件夹排在前面。点击文件直接预览，文本编辑为单独操作；重命名、删除和未保存内容保护沿用原有流程。PDF 支持输入页码与适宽；图片提供缩放，文本可切换换行；Office 文档按章节／工作表切换，表格显示行列索引，ZIP 目录可按名字筛选。没有增加服务端写操作。

工作台和 ZIP 目录每次先显示 80 项，可逐步展开；切换文件夹时清空旧筛选，切换文档页码／章节时回到阅读区顶部，避免保留上一页的滚动位置。

本轮界面调整的发布前测试记录见下方「验证边界」；未进行应用启动或视觉验收。

1.4.4 发布前已按新增授权运行 `pnpm test`，前端 **73 项通过**（包含全部 Vue 组件与模板的内存校验）。这不包含应用构建或真机视觉验收。

## 保存

- `remote_download_resource` 使用原生 HTTP 流逐块写入专用临时文件，不将文件转成 JSON 字节数组传给 WebView。单任务上限 2 GiB，不再受普通接口的 8 MiB 响应上限限制；同时允许一个下载任务。
- 界面显示进度和保存阶段，支持取消。模式切换会终止旧连接的下载；复制到目标文件时也检查旧模式是否失效。网络失败、取消、长度不符或保存失败不会显示成功，不自动重试或覆盖现有文件。
- 下载空闲超时 45 秒，总请求超时 30 分钟。已知长度会在接收前后校验，未知长度也持续检查上限；没有实现断点续传或应用退出后的持续下载。
- 临时文件按任务清理；异常退出的残留在下次初始化时清理。原件只在用户明确保存后进入导出位置，不进入会话投影缓存。
- Android 使用系统文档创建选择器，支持二进制文件，不申请整盘存储权限。后台线程以有界缓冲复制；JNI 运行门阻止已失效模式继续写入。取消、失败时尝试删除系统选择器创建的不完整目标；部分文档提供方可能拒绝删除，此时需在该提供方中清理。
- Windows 等桌面平台保存到下载目录，文件名添加唯一前缀，避免覆盖同名文件。iOS 保存到应用的“文稿/infOS导出”，通过“文件”App 查看；启用文档共享，业务数据继续保留在应用数据目录。
- 现有配置、角色包、提示词及会话 JSON 导出保持原有文本导出接口；不是二进制附件打包导出。

## 预览

| 格式 | 显示方式与限制 |
| --- | --- |
| 图片／GIF、音频、视频 | 消息内被动媒体控件及放大阅读；BMP、ICO、AVIF 等按设备能力解码。小图片自动读取上限 8 MiB，音视频及较大图片显式加载；完整预览上限 100 MiB，按原生 Range 分段拼接 Blob，设备编解码不支持或超限时可保存原件。不是媒体边下边播 |
| 文本、代码、JSON、XML | UTF-8 源码预览，完整面板最多前 256 KiB，小窗最多前 64 KiB；大文本通过 Range 读取前缀，不整份装入内存 |
| MD／Markdown | 小窗正文片段，展开后富文本阅读；代码、公式、表格、资源链接使用与对话一致的阅读组件 |
| HTML | 小窗隔离预览；完整面板优先使用 infOS `browser-preview` 短期票据，支持工作区相对资源，不携带设备授权头。旧服务端退回自包含 iframe 预览；源码随时可看。票据过期可刷新。页面不具有同源或原生桥权限 |
| SVG | 隔离 iframe 预览与源码切换；自包含预览不读取网络或服务器外部资源。截断内容只显示源码，不执行不完整预览 |
| PDF | 本地 PDF.js 引擎与字体资源，逐页画布、翻页、缩放、密码输入；优先使用鉴权原生 Range，关闭自动预取。文件最大 512 MiB，每次只绘制一页、画布最多约 400 万像素；不提供脚本、活动表单或链接执行 |
| DOCX | 正文文字速览，保留段落；不还原图片、样式、分页或复杂版面 |
| DOC | Worker 内提取未加密的 Word 97–2003 正文片段；不执行宏或嵌入对象；更早版本、损坏或加密文件回退原件 |
| XLSX | 工作表及缓存单元格值；不计算公式、还原样式或日期格式，每表最多 200 行、30 列 |
| PPTX | 各页文字速览，不还原幻灯片布局、图片或动画 |
| CSV | 支持引号与换行的表格速览，最多 200 行、30 列 |
| ZIP | 目录与条目大小，最多显示 600 项，不解压到设备文件系统 |
| ODT／ODS／ODP、EPUB、RTF | 提供文本内容速览；不还原原始版面、交互或资源；加密与损坏文件回退原件 |
| DOCM／XLSM／PPTM | 只读取对应正文／工作表／幻灯片 XML；宏不会载入或执行 |
| 其他格式、旧版 XLS/PPT、XLSB、加密 Office、RAR/7z | 保留文件小窗、元数据、点击进入阅读面板和保存原件入口；不声称已解析正文 |

Office 与 ZIP 的输入上限 8 MiB，解包在独立 Worker 中执行，超时会终止。扫描目录最多 10000 项；Office 最多提取 50 个正文分部，每个 XML 上限 2 MiB、累计上限 8 MiB。XML 拒绝 DTD/实体声明，显示只使用 Vue 文本与表格，不执行宏、外部引用或文档脚本。达到限制会提示截断或回退到保存原件。

文件预览任务最多并发两个；小窗进入可见区后才开始读取。离开可见区后停止播放器，PDF／HTML 预览卸载，闲置媒体 Blob 随后释放。HTML 票据使用 infOS 服务端的 10 MB 限制；自包含源码预览仍受文本前缀限制。公开外链可能受到 CORS、TLS 或设备网络策略限制，失败时保留系统打开入口。保存原件仍由原生流处理，和 WebView 的预览上限分开。

## 验证边界

1.4.5 发布前按用户授权执行 `corepack pnpm@10.34.7 test`，前端 **86 项全部通过**，包含全部 Vue 组件与模板的内存校验；执行 `cargo test --manifest-path src-tauri/Cargo.toml --lib`，Rust 后端 **103 项全部通过**。

既有 Rust 回归覆盖流式二进制保真、中途断流失败、大小限制、临时文件清理、Range 响应一致性、资源路由约束及文件名处理。Android 的 JNI 守卫也纳入主机测试的编译范围；Kotlin、系统文件选择器与文档预览尚未真机验证。

未运行独立类型／静态检查、本地应用构建、Android/iOS 打包、Tauri 启动或真机联调。新增富文本、DOC 提取、HTML 票据接线、媒体小窗及生命周期处理尚缺少真实服务端和设备的端到端验收，现有测试不代表各系统文件提供方、PDF 和 Office 预览已全部验证。
