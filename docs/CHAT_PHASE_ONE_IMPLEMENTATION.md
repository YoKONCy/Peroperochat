# 对话体验一期实装记录

本轮依据 `docs/design/chat-phase-one/` 接入正式 Vue 对话页面，仅修改 PeroperoChat，未修改 infOS。实装内容随 1.4.5 发布，版本元数据与 `v1.4.5` 标签保持一致。

## 视觉与交互

- 定稿的 32 个受信任 SVG 图标进入应用常量，增补公式、图表、表格和播放操作；无 emoji 图标。
- 浅／暗主题继续复用配色包与角色外观配置，不将 Pero／Nana 身份、头像或台词固定在组件里。
- 消息头像行与角色正文气泡、云签式思考、开放式工具轨迹、NIT 子调用、暖色审批和叠纸折叠队列分别处理。
- 输入区保留已接通的模型、思考强度、执行与工具配置；修改的是形式、密度、热区及状态反馈。
- 抽屉、页面与按压使用短过渡；系统及应用减少动态设置均可关闭。保留已有草稿、队列修订、回滚与重新生成的业务处理，不新增单条消息删除。

## 渲染链路

`RemoteRichText` 持有每个正文节点的增量分段器。稳定块分别交给 `RemoteRichBlock`，活跃尾部使用 `RemoteStreamText` 追加文本节点；不再为每次正文增量整段替换 Markdown DOM。停止或失败后，未闭合围栏、公式、HTML 保留原文。

稳定块支持 Markdown、代码面板、公式、Mermaid、HTML／SVG 和独立资源引用。代码按需高亮，可复制、换行、展开；表格固定首列并局部横滑；公式使用 KaTeX，图表使用 Mermaid 严格模式和二次净化，可展开缩放。解析失败不阻断其他块。

HTML 正文使用独立无同源 iframe 与 CSP，自包含预览不能读取网络或应用原生桥；文件 HTML 可通过原生层申请 infOS 已有短期票据，使用服务端限制的相对工作区资源。前端不接收设备凭据。隐藏或离开可见区后卸载 iframe；后续重新可见时按需要重新加载，不在流式增量中反复初始化。

异步排版和媒体加载通知主会话维护滚动位置；阅读历史时显示回到底部入口，不强制跟随。工具与思考仍来自真实 Surface，未增加模型进度推测或自动概述。

## 文件入口与边界

`RemoteResourceCard` 将附件、正文资源引用、`send_file` 返回及读图／截图结果连接到同一套预览。图片／GIF、音频、视频在消息内查看；文档留出固定小窗，点击跳到 `RemoteResource` 阅读面板。MD 文件中的后续资源引用也能继续打开。

新增 Rust 转发：

- `remote_resolve_resource` → `/api/attachments/resolve-reference`，使用会话上下文解析来源。
- `Resource::Reference` → `/api/attachments/reference-content`，仅允许已解析的工作区引用。
- `remote_html_preview` → `/api/attachments/browser-preview`，只接受受控资源，校验 `/html-previews/` 随机票据格式。

所有私有资源沿用模式令牌与原生鉴权；公开外链不携带设备授权。无法解码、权限失效、跨域失败、损坏、加密或超限均保留原件／系统打开入口。各格式实际能力与大小限制见 `docs/REMOTE_FILES.md`，内容速览不代表完整原始排版。

依赖新增固定版本 `highlight.js@11.11.1`、`katex@0.18.4`、`mermaid@11.16.1`，与所参考 infOS 前端一致。锁文件和本地依赖已同步，安装使用 `--ignore-scripts`，没有执行依赖构建脚本。

## 1.4.5 发布后的长对话与提示修复

- 普通接口的响应保护不再直接限制整页聊天：历史页自动缩小，单条长消息及队列／任务投影使用独立额度；离线缓存不足不再造成在线读取失败。服务端分页游标及内容保持完整，没有截短消息来消除报错。
- 同一模式、连接和参数的并行读取合并，缓存读取与在线读取分别处理；仅对 `REMOTE_STALE_READ` 做有界静默重试，仍在变化时延后刷新，不重放任何写操作。单个接口解析失败不再将整个连接标为不可用。
- 会话核验遇到短暂网络问题后自动重试；已经核验成功时，订阅暂时断线不再使输入框一直不可用。对话载入失败与真实空会话分开显示。
- 通知、连接与后台设置删除实现细节说明；错误码在展示边界转换为简短说明，原机器状态与操作身份继续供业务层使用。
- 常规提示统一为可关闭的轻提示，约 5.5 秒后自动收起，悬停或聚焦时暂停；同一组件的重复后台错误在 30 秒内不重弹。切换页面或连接时清除旧提示，重新连上后清除连接错误。登录失效、未保存草稿、结果待确认等状态仍保留相应操作入口。
- 本轮前端 **94 项**、Rust 后端 **108 项**测试通过，新增覆盖自动分页、超过旧上限的单条读取、无长度响应的边界、缓存不阻断在线结果、并行读取、模式隔离、静默重试与提示生命周期。未进行本地应用构建、打包、启动或真机联调。

## 对照手机截图后的对话页结构纠偏

- 对话页改为独立阅读空间：角色头像、名称与话题组成顶栏；底部五栏导航在会话中收起，通过返回首页或更多面板访问其他页面。角色、配色、头像及话题均取现有配置。
- 输入改为配置、正文输入、轻工具三行。模型／思考强度为行内入口，上下文用量位于同一配置行；模式只显示当前选项。图片方式、工作区引用及低频操作进入抽屉，健康状态下不再常驻服务端保存说明。键盘打开时收起轻工具行。
- 队列仅显示短摘要，消息正文及编辑、排序、立即发送、取消等操作进入抽屉。错误不会强制展开。编辑保留最初修订号；别处修改后不覆盖，队列移除消息后仍保留正在编辑的文字，离开前保护未保存修改。
- 使用独立的 `chat-*` 布局类，删除旧输入区规则及固定浮动按钮偏移。消息舞台与输入区分开，“回到最新”锚定舞台；尺寸变化复用现有阅读锚点与跟随逻辑。
- 正文统一 16px／1.8 行高，工具标题 13px、角色信息和思考标题 12px、说明与时间 10–11px；段落、字重和颜色有明确层级。代码继续使用等宽字体，抽屉采用同一字体回退链，角色样式包的配色与气泡选择仍生效。
- 白纸气泡、雾色云签、开放式工具轨迹、暖色审批、文件小窗各保留不同材质。连续工具以细线组织，完成状态收成图标，轮次与耗时为辅助信息；NIT 子步骤仍可展开。按压、出现与执行状态只使用短过渡和轻脉冲，尊重减少动态设置。
- 完整前端测试 **94 项通过**，包含 Vue 脚本与模板内存校验；此次界面重排未修改 Rust。未运行应用构建、打包、Tauri 或视觉验收程序，也未在手机上验证最终排版，不能将源码及测试结果视为视觉还原已获确认。

## 富文本排版细化

- 正文调整为 15.5px／1.85 行高，思考保持 13px，文件阅读为 15px；移除聊天页覆盖标题、段落、列表和代码的重复规则。流式分块保留原有块类型，标题与正文之间使用不同间距，避免每个标题都被当成段落开头压平。
- 一级标题采用短渐变下划线，二级标题使用菱形标记，三级标题采用细竖签；重点文字以较深墨色与轻底纹区分。引用改为书签便笺，列表和任务清单使用独立标记，分隔线保留小型几何装饰。
- 表格增加实色表头、交替行底色和首列强调，仍支持横向滑动及展开。代码采用深墨底与高对比语法色；图表使用浅点阵，公式使用干净渐变纸面，HTML 保留独立预览。工具栏提供简短按钮、窄屏图标和无障碍名称；预览提示简化为用户文案。
- 这一轮仅进行源码与 Git 差异审阅，未执行测试、构建、打包或启动视觉验收。上文测试数字为前一轮结果；当前浅深色与手机最终显示仍需实际确认。

## 轻气泡反馈

- 远程错误、保存结果及本地页面的普通消息统一交给应用级浮层，移除顶部提示条。气泡使用小图章、几何点缀、短弹入和淡出，显示在可见屏幕下部；键盘出现时跟随可见区域，空白浮层不拦截触摸。
- 成功提示默认约 2.8 秒，其他提示约 4.8 秒；同一时刻只显示一个，重复提示合并，队列有上限并丢弃过时提醒。悬停、聚焦、进入后台时暂停计时，切换路由或运行模式清除旧反馈。重试按钮主动操作后允许再次反馈结果。
- 本地房间、群聊、设置、衣柜、日记、提醒与远程文件保存等入口使用同一气泡；读取失败的重试入口仍可从对应页面操作。历史执行结果、审批和未保存确认继续保留在它们所属的内容中。
- 气泡沿用来源页面的角色主题与减少动态设置，抽屉中归属当前对话框以保留键盘导航。此次仅做源码与差异审阅，未运行测试、构建、打包或启动应用。

## 空间切换与连接面板整理

- 独立与远程模式共用「切换空间」面板，首屏保留两种空间入口及连接列表；删除重复说明、大块在线通知介绍和常驻配对表单。添加、手动填写、更多登录方式与通知设置按需展开。
- 连接卡片分为名称／地址区、状态标记、操作区；长名称及地址单行省略，完整内容放在更多详情中。自动生成的节点名使用简短尾号显示，保存的数据不改动；授权日期不再与名称、按钮挤在同一行。移除与重新配对进入独立操作区，过期的当前连接也保留直接重新配对入口。
- 替换产生横排冲突的旧样式，连接面板使用独立布局类；扫码、链接采用专用 SVG 图标。后台接收只在通知选项展开时读取，相关提示合并为当前最需要处理的一条。
- 扫码与粘贴仍需核对地址后提交，未加密连接仍需明确勾选；收起或更换配对表单后不再接受之前迟到的解析结果。本轮仅审阅源码与 Git 差异，未运行测试、构建、打包或启动应用。
