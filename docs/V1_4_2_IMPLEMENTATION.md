# 1.4.2 实装记录

## 远程接收适配

- Android 新增可选择开启的原生后台接收服务，使用独立进程与持久连接接收 infOS 已有通知，提供连接通知和通知点击后的页面交接。
- 凭据继续使用系统 Keystore，跨进程读取使用原子文件；保留旧凭据迁移。后台接收与运行模式、连接及激活代次绑定，切回独立模式时停止远程接收。
- 未修改 infOS 服务端，没有引入 FCM、APNs 或厂商推送。进程回收、Doze、强制停止和厂商后台策略仍影响到达能力，不承诺退出后实时投递。
- 具体范围、历史 Rust 测试记录及 Android 真机验证边界见 [Android 远程后台通知](ANDROID_REMOTE_NOTIFICATIONS.md)。

## 房间与本地交互

- Nana 默认房间更新为独立插画；自定义角色自动房间默认跟随 Pero，可上传固定背景。
- 两个默认房间均有白天、晨昏和夜晚三种背景。前端在进入或切回房间时传入设备时区偏移，Rust 决定时段与素材；持续停留时不定时刷新，上传的固定背景不参与自动切换。
- 本地聊天气泡、提醒条、快捷入口、衣柜、日记与抽屉统一轮廓和配色，使用静态 SVG 点缀。
- Live2D 互动台词改为无底框悬浮文字，轻微错位、逐字冒出后淡去；聊天回复继续使用消息气泡。动画节点数量有上限，支持减少动画偏好。
- 本地开关共用 `RoomSwitch`；复选框、单选框和滑杆使用应用外观。配色、连接方式及任务状态复用选择抽屉，保留焦点、禁用与原生表单语义。
- 背景素材与时段规则见 [房间背景记录](../public/companion/ROOM_BACKGROUNDS.md)、[房间时段背景](../public/companion/ROOM_TIME_VARIANTS.md)；界面说明见 [陪伴房间 UI](COMPANION_ROOM_UI.md)。

## 发布与验证边界

版本统一更新至 `1.4.2`：`package.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 与 `src-tauri/tauri.conf.json`。Android 的版本名称与版本代码由 Tauri 在 CI 中生成，不手动修改忽略跟踪的 `tauri.properties`。

本次版本整理仅进行源码差异和元数据审阅，没有重新运行测试、ESLint、构建、Tauri 或移动端打包。后台接收阶段和时段背景阶段此前执行的定向 Rust 验证不代表此次完整版本已通过运行验收；本地 UI、Android 原生服务、通知点击、功耗与覆盖更新仍需实际设备确认。

推送 `v1.4.2` 标签后，由现有 GitHub Actions 工作流执行远程 Android 打包与发布。
