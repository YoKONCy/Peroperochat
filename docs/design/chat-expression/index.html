EXPRESSION & REASONING · DESIGN 04

一点小动作，一圈小星轨。

旁白轻轻出现；思考有自己的表情。沿用八套配色，保持正文的阅读优先级。

01 / PARENTHETICAL

像轻声旁白，仍在句子里。

全角“（）”内容使用较轻字重、柔和对比和细小起笔装饰。长旁白自然换行，不做一串胶囊标签。内部强调、链接保留原有功能。

半角代码、公式、网址、引用标识不套这层视觉。未闭合括号在流式输入中保持正文样式；闭合后轻淡入，不把整段文字重新打字。

02 / REASONING

强度看形状，运行看动静。

关闭 / 自动 / 低 / 中 / 高 / 极高 / 最高，各有图形轮廓与色调。正文保持安静，只在选择器、输入栏小标识和展开的思考头部出现。

动效只表示正在思考，不代表剩余时间、成功率或完成进度。结束后静止；历史记录只使用该次请求实际记录的强度，不拿当前设置回填。

FORM, COLOR & MOTION

七种状态，不靠文字硬分。

每个循环约 2.4–4.8 秒 · 只动小图形，不动正文布局 · 失焦暂停 · 减少动态时静态显示

独立 HTML / CSS / SVG 设计稿，含可交互示例。括号渲染与思考动效尚未写入应用。
