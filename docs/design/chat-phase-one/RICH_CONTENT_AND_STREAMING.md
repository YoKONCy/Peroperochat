# 一期：富内容与流式阅读设计

本文件补充对话体验一期设计，供视觉与交互评审。没有接入应用、服务端或正式标记语言解析器。

## 内容形态与阅读方式

| 内容 | 消息中的视觉 | 交互与边界 |
| --- | --- | --- |
| Markdown | 舒展的文档气泡；标题、引用、清单、链接有层级 | 长文保留正常字号；清单只是消息内容，不直接修改任务 |
| 代码 | 独立代码面板，语言标签与操作栏分开 | 保留缩进；局部横滑；换行、复制、展开；未知语言退为纯文本 |
| XML | 以源码与语法色呈现 | 普通 XML 不当成网页执行 |
| 表格 | 表头轻底色，行线与正文有明确区分 | 局部横滑；默认固定第一列；展开后使用较宽阅读区域 |
| 数学 | 独立留白区，基线与正文分层 | 行内与块级公式沿用 infOS 语义；长公式局部横滑；失败可看原文 |
| Mermaid | 轻画布与小型工具栏 | 结构稳定后绘制；展开、放大、适应画布、源码和失败退回 |
| HTML／SVG | 独立预览容器，与普通气泡明显区分 | 稳定后加载；预览与源码切换；独立展开；不能侵入聊天页样式 |
| 图片 | 预留媒体比例与简洁说明 | 查看大图；加载与失败保留版面空间 |
| 会话资源 | 文件标记、名称和类型分层 | 显式打开；权限与下载失败原位提示；不能假定所有路径均可访问 |
| 解析失败 | 轻提示与原文入口 | 保留原文与复制能力；不阻断下一条消息 |

引用的分隔线、色块与清单标记服务于阅读，不模拟工具调用、审批或任务卡片。工具、思考、队列使用之前的专用组件，避免把结构化事件混成正文。

## 流式阅读契约

1. 已稳定内容保持原位。只有当前活跃尾部持续追加文字，避免整条消息反复入场、高亮或重新初始化预览。
2. 结构未闭合时显示原文。代码、公式、表格、HTML 与图表在合适边界稳定后才进入对应排版；最后一个仍可能延续的段落保留尾部身份。
3. 思考、正文与工具事件独立显示。只呈现服务端实际返回的记录；不给工具动作编造完成状态、进度百分比或额外摘要。
4. 用户停留底部才跟随。往上阅读后只出现“回复还在继续 · 回到底部”，不抢阅读位置；横滑代码与表格不应被当成切换页面手势。
5. 停止后保留已收内容。未完成结构留原文，并显示停止状态，不能补造闭合标记后宣称生成完成。
6. 断线与完成分开。恢复时以服务端权威状态接续，不通过重新发送原消息伪装为重连；必要时只修订受影响内容。
7. 内容修订应保留阅读锚点，不重播整页动效。实际节点复用、滚动补偿、UTF-16 边界与选区保护在正式实现阶段处理。
8. 预览与媒体异步加载应避免顶开已读区域。正式端需处理图片尺寸未知、iframe 高度变化与资源权限错误。
9. 减少动态时关闭装饰性过渡，继续正常显示增量。页面后台与组件不可见时的调度遵循正式端生命周期，不将暂停设计演示等同于暂停服务端任务。

## 动效、手势与可访问性

- 文字不逐字弹跳、不整屏闪烁；结构稳定时以局部替换为主，过渡仅帮助理解状态交接。
- 顶栏和输入浮层可保留薄玻璃，富文本、代码与工具区域避免大面积实时模糊。
- 主要操作热区至少 44 × 44 CSS 像素；辅助图标仍需足够热区，不能按图形尺寸直接裁小按钮。
- 状态同时使用文字和图标。复制失败提示手动选取；展开阅读可用 Escape 关闭，并返回原入口。
- 正式接入需保留语义表格、公式可访问文本、代码选择、资源名称与非颜色状态提示。

## 本次交付的实际范围

网页新增六屏排版、固定样例展开与流式交互演示；两张新增画板使用 SVG 原语绘制，再导出 PNG，属于独立设计资产。HTML 画面为可信的固定示例，Mermaid 为预绘 SVG，公式为固定 MathML；流式演示在预设块边界替换预绘内容，没有实际解析任意输入。

演示支持不均匀分块、播放、暂停、停止、模拟断线／恢复、翻看历史、回到底部及速度切换。它不验证网络重连、服务端持久化、安全沙箱或实际渲染性能。

内置浏览器不允许代理直接加载此本地 `file://` 页面，因此没有通过其他入口绕过限制。静态画板已导出供目视评审，交互页面尚未经浏览器核验。本轮没有运行应用测试、构建或启动应用。
