# 对话体验一期设计稿

直接用浏览器打开 `index.html`。不需要依赖安装、开发服务器或构建。

`conversation-overview.png` / `.svg` 是六屏静态总览，`component-language.png` / `.svg` 是组件与图标板。静态画板采用 SVG 原语单独排版，非浏览器截图；内置浏览器当前禁止代理直接加载本地 `file://`，所以交互网页尚未经浏览器核验。静态导出只进行设计图绘制，没有启动开发服务器或应用。

新增 `rich-content-overview.png` / `.svg`（六屏富内容）和 `streaming-storyboard.png` / `.svg`（流式状态分镜）。网页顶部的「富内容」「流式体验」可切换到对应演示。详细范围及 infOS 源码对照见 [富内容与流式设计说明](RICH_CONTENT_AND_STREAMING.md)。

本目录为独立 HTML / CSS / SVG 设计演示，没有导入应用代码，不连接 infOS、不访问麦克风、不写入应用数据。角色素材引用之前已定稿的角色头像与 CG，没有改动原素材。

## 画板内容

- 六个移动端场景：日常聊天、思考与工具执行、审批确认、队列与文件结果、模型与思考强度、消息编辑。
- 八类组件细节：对话气泡、思考、工具轨迹、NIT 层级、文件、审批、队列、按钮与状态。
- 三十二个定制 SVG 图标与基础配色、文字、触控、材质规范。
- 四组轻动效：消息出现、抽屉、执行状态交接、页面切换；支持减少动态。
- 六屏富内容：Markdown 长回复、代码与 XML、表格与公式、HTML／SVG、Mermaid、图片与资源退回；增补十个专项 SVG 图标。
- 流式演示：不均匀分块、稳定块与原文尾部、暂停、停止、模拟断线／恢复、翻看历史和八类边界状态。

浅色与暗色是同一套组件语言的两个主题。示例角色与展示主题相互独立，正式实现时身份、头像、文案和配色仍由角色配置提供。角色立绘在高信息量对话中常态收起，不把每条内容做成角色海报。

## 可点击的地方

思考折叠、工具与 NIT 子调用、文件预览、队列展开、消息操作、模型与思考强度、工具设置、附件菜单、会话切换与输入发送均有界面演示。演示按钮会明确提示没有执行真实操作。

消息内容与工具记录都是示例。轨迹只设计真实服务端字段的展示，不引入任务自动概述、伪造进度或不存在的单条消息删除。正式业务仍由 Rust 和 infOS 执行。

富内容提供固定样例的横滑、换行、复制、展开阅读、图表缩放、HTML 预览／源码切换与原文退回。复制仅由显式按钮触发；浏览器不允许剪贴板时提示手动选取。示例没有引入正式 Markdown、KaTeX 或 Mermaid 引擎，也不会执行模型生成的网页。流式演示使用预设分块与预绘内容，不能作为真实网络恢复或渲染性能已达标的证据。

## 待评审

- 二次元感与信息密度是否平衡，组件形状是否足够区分。
- 云签式思考、开放式轨迹、叠纸队列是否自然且好用。
- 玻璃感和装饰的克制程度、默认浅暗主题的舒适度。

用户确认设计后，再接入正式 Vue 组件。本次不修改应用实现，不执行测试、构建或应用启动。
