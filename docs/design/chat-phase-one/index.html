04 / LITTLE RESPONSES, BIG DIFFERENCE

轻轻回应你，别打断你。

点击各个演示按钮。动效用于解释变化，避免持续摇晃和夸张弹跳。

110ms按压 · 轻缩 2%180ms消息 · 上浮 6px240ms抽屉 · 贴着手势出现160ms切页 · 方向一致

尊重“减少动态”。自动滚动仅在用户停留底部时发生；阅读历史时只提示新消息。草稿、滚动位置和展开态应由正式应用保留。

05 / MORE THAN PLAIN WORDS

每一种内容，都有舒服的读法。

对照 infOS 当前渲染链路补充。下列为固定样例排版，尚未接入正式解析器。

01

正文先舒服

标题、段落、引用和清单保持阅读节奏。文档长了可以展开，不把字号越缩越小。

02

宽内容有自己的空间

代码、表格与长公式独立横滑。图表可放大，HTML 在内容稳定后进入隔离预览。

03

不把标记变成误操作

任务清单是回复内容，不直接修改任务；资源链接显式打开，XML 和未知标记可回看原文。

06 / CONTINUITY, NOT A TYPEWRITER

一段段到来，读起来仍是连续的。

模拟不均匀分块与内容稳定过程；这是交互设计演示，不是网络或渲染性能测试。

对齐的是当前主渲染链路

稳定块保持节点，活跃尾部追加文字。代码、表格、公式和 HTML 在结构稳定后排版；HTML／SVG 不随每个字符重启预览。实际分块规则、资源加载和性能由后续正式实现验证。

示例中的 Mermaid 与 HTML 画面为预先绘制的内容；数学排版使用固定 MathML 示例。这里没有引入完整标记语言解析器或执行模型生成的网页脚本。
