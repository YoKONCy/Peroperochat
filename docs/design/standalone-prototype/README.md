# 独立模式 · 轻透日常 · Web 设计稿

以用户认可的 `../standalone-concepts/standalone-light-v2.png` 为布局和材质依据，实现房间、对话、衣柜、设置四页。文字、气泡、玻璃、按钮和弹层由 HTML/CSS 排版，功能图标为手写 SVG。

## 当前方案

自制动态立绘试作已停止。网页稿使用 `assets/pero-standing.svg` 静态原画，保留角色原来的造型和细节；不加载试作模型、透明分层缓存、动画控制器或角色互动循环。

此稿的视觉现已接入正式应用，正式应用支持随时切换 Pio Live2D 与角色静态立绘／CG，并由 Rust 保存显示偏好。网页稿自身仍只演示静态图片。详见 [独立模式 UI 实装说明](../../STANDALONE_UI_IMPLEMENTATION.md)。

## 查看

直接打开本目录的 `index.html`。全部脚本使用有序的普通脚本加载，资源为相对本地文件，无外部字体、CDN、依赖安装、API 请求或开发服务器。

提供四页总览与单机交互预览，窄屏自动调整为单列。本设计稿不替换正式应用、Rust 数据层或远程客户端设计稿。

## 设计交互

- 房间功能入口、菜单、页面切换、返回与收起对话。
- 消息输入、Enter 发送、Shift+Enter 换行，兼容中文输入法确认；回复为预设演示内容，不调用模型，最多保留 60 条演示消息。
- 附件仅记录所选文件名，不读取图片、不上传。
- 服装缩略图与选中态、演示日记阅读、提醒时间与内容编辑。
- 设置列表、模型字段层级展示、角色显示名字和问候文案编辑。
- 点缀配色、玻璃不透明度、角色显示大小与界面动效开关；立绘本身保持静止。
- 恢复演示状态；所有数据仅在页面内存中，不写浏览器存储，不读应用配置、密钥和数据库。

## 素材与边界

`assets/sunlit-room.png` 是独立的房间插画；`assets/pero-standing.svg` 是原画路径立绘，原始透明 PNG 保留为 `assets/pero-standing.png`。SVG 不嵌入位图，不会凭空生成原画没有的细节。来源和制作记录见 `PROMPTS.md`。

默认角色高度为屏幕的 57%，脚底靠近输入区。背景、角色、气泡和面板独立，聊天和衣柜使用各自的构图。

头像来自项目现有 `public/avatars/pero.jpg`。衣柜复用项目 Pio 服装贴图的主体裁切，仅展示缩略图和选中态；网页稿不加载 Pio，也不模拟换装成功。正式应用的 Pio 模型与服装资源继续保留。

模型表单只展示字段层级，没有真实连接、密钥输入或参数持久化。提醒不设置闹钟或通知；日记为预置演示内容；数据与备份入口不提供实际清空或备份操作。

角色内容由 `data.js` 提供，组件根据数据组合展示。晴空蓝是本轮标准浅色；其他点缀色用于检查配色解耦，不表示暗色定稿已获认可。本轮不增加角色包安装器。

## 文件

| 文件 | 职责 |
| --- | --- |
| `index.html` | 设计工作台与预览入口 |
| `icons.js` | 固定 SVG 功能图标 |

旧 `puppet*`、`original-puppet*`、`prepare-original-*` 文件和对应分层素材只留作历史实验资料，主设计稿不引用它们。自制动态立绘的尝试和停止决定记录在 `PROMPTS.md`。
