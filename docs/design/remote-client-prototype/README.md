# PeroperoChat 远程客户端 Web 设计原型

本目录将已定稿的 Pero 标准浅色、Nana 标准暗色设计实现为真正的 HTML/CSS 页面。界面文字、导航、气泡、卡片和时间线均由浏览器排版；只有角色 CG 和头像使用位图。图标和装饰使用 SVG。

## 查看方式

直接用本机浏览器打开 `index.html`。无需安装依赖、启动服务或构建项目；脚本采用有顺序的普通脚本加载，支持本地文件打开。

内置浏览器的 URL 策略拒绝 `file://` 地址，因此本轮没有在内置浏览器中展示或执行浏览器验收。没有运行前后端测试、构建或 Tauri。

## 页面与交互

- 双主题总览：并排展示首页、会话、执行详情、资料，分别使用 Pero 浅色和 Nana 暗色。
- 交互预览：独立选择角色、浅暗主题，体验导航、返回、消息输入、工具记录折叠、文件与记忆分类、搜索、文件预览、确认状态和显示偏好。
- 组件与配色：对照查看六类复用组件、八组配色与两张独立 CG。
- 点击首页 CG 或会话展开按钮，查看独立插画；首页也可以切换为头像布局。
- 演示输入支持 Enter 发送、Shift+Enter 换行，并避免中文输入法确认候选时误发送。
- 文件下载提供明确标注的 `.txt` 示例内容；预览中的 PDF、XLSX、MD 卡片用于表现远程产物的显示方式。
- 在 Nana 的显示偏好中启用“星纹缎带”，可以查看预置角色 CSS 对标准组件的样式覆盖。
- 尊重系统减少动效偏好；图标按钮具有中文无障碍标签，弹层使用原生 `dialog`。

本次视觉润色重画了双色功能图标、折纸缎带、月夜星轨、山景与三种文件封面 SVG；细化姓名签、发言尖角、导航图标底座、执行节点、确认卡片与按钮材质。组件与配色页面新增图标对照册，可直接查看浅暗两种图标效果。

这是设计原型，不连接 infOS 服务端。聊天回复、任务状态、远程记忆与文件均为示例。确认操作只切换演示状态，附件只显示所选文件名，不读取或上传文件。不会读取现有应用的数据库、API 密钥或远程连接配置。

显示偏好使用独立的 `peropero-design-preview-v1` 本地存储键。浏览器禁止本地存储时，自动使用默认状态。消息只存在于当前页面内存中；两个角色的演示消息分开保存。

## 主题和角色包约定

1. **标准外观**：浅色沿用 Pero 的蓝白、折角、缎带语言；暗色沿用 Nana 的紫色、玫瑰点缀与星轨语言。角色和明暗主题不强制绑定。
2. **配色包**：晴空蓝、月夜紫、樱花粉、薄荷青、琥珀金、绯红、银雾、桃橙。每组提供浅暗两套主色、底色、点缀色。文字、边界、弱填充由共享规则生成，成功和异常状态单独设置。正式接入前仍需逐组确认可读性。
3. **角色内容**：名称、头像、CG、展示焦点和角色文案集中在 `data.js`。普通应用操作文案由组件提供，角色实际发言由消息数据提供。
4. **角色样式**：示例 CSS 通过 `.device[data-role="nana"][data-skin="character"]` 限定作用范围，覆盖气泡、边框和装饰，不接管连接、消息处理或持久化。
5. **覆盖次序**：标准布局和浅暗主题 → 配色变量 → 可选角色组件样式；用户选择明暗、配色和是否显示 CG。未提供的部分继承标准主题。

本轮只演示预置样式包，没有实现外部包导入、任意 CSS 加载或安装器。正式接入时需要对资源路径、CSS 选择器和外部资源引用设定约束；选择器前缀本身不作为安全隔离机制。

## 与现有应用的关系

原型独立放置在文档目录，没有替换 `src/` 中的生产页面，也没有调整 Rust 后端。它用于确认真实 Web 排版、素材、组件和交互，再将选定结构迁移到应用。
