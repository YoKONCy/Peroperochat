# 陪伴房间 UI

独立模式首页采用角色优先的二次元陪伴界面。根据 N.E.K.O. 移动端、Aiko 和逗逗的公开界面参考，将原先偏手账的配色、衬线标题与大面积底部面板调整为大角色、轻控件和悬浮输入栏。PeroperoChat 仍使用现有 Live2D 模型、Rust 会话服务和 TDB 日记，不新增房间编辑、走动或家具交互。

参考来源：[N.E.K.O. 官方 TapTap](https://www.taptap.cn/app/881696)、[Aiko 官方 App Store](https://apps.apple.com/us/app/aiko-your-ai-soulmate/id6754183676)、[逗逗官方 TapTap](https://www.taptap.cn/app/608870)。参考公开截图的布局和视觉层级，不复制其功能、角色资产或付费养成机制。

## 本地气泡与小组件细化

- Live2D 互动、欢迎和闲置台词采用旧版无底框悬浮字的方向：白色文字光晕、轻微错位、逐字冒出与结束淡去。字符只播放一次出现动画，展示节点有上限，支持组合字符与减少动画偏好；文字穿透点击，切换角色、展开聊天、打开抽屉或切入后台时清理台词。
- 聊天回复预览和静态立绘台词采用名字签、双层细描边和可见尾巴，点缀静态星芒与轨道 SVG；长角色名截断显示，按钮保留完整的无障碍名称。
- 对话区区分角色回复和用户消息的尾巴方向、名字标签与底色。思考折叠、最近回复、输入栏和发送按钮同步统一轮廓，消息操作与流式渲染逻辑沿用原实现。
- 快捷入口、提醒条、抽屉标题、衣柜选中态、日记与提醒卡片共享配色和细描边。装饰跟随现有配色包，不绑定角色姓名与身份。
- 房间装饰样式限定在 `standalone-design`；远程抽屉不渲染本地装饰。仅小控件保留原有的轻量玻璃采样，没有新增常驻动画、粒子或全屏模糊，减少动画偏好继续生效。
- 动效、流式回复与群聊成员开关共用 `RoomSwitch`，具有 44px 点击区域；复选框、单选框和滑杆自行绘制外观，保留键盘、焦点、禁用与原生表单语义。配色、连接方式和任务状态复用应用内选择抽屉，避免弹出安卓原生选项列表；日期和时间仍使用系统选择器。
- 此次仅进行源码和 Git 差异审阅，未运行测试、构建或启动程序，实际视觉尚未运行确认。

## 本地工具时间线

- 单聊和家庭群聊的角色消息增加默认折叠的「工具 · N 项」。展开后按调用顺序显示工具名称、状态和一行结果，例如「查日记 · 完成」「找到 2 篇日记」，不铺开参数或整批查询内容。
- 调用过程中显示「进行中」「待保存」；写入只在回复与副作用事务成功提交后显示「已保存／已更新」。取消、失败或进程中断后的待写入操作显示「未保存」，不会冒充成功。
- 简短时间线随消息保存，重新进入、重启、备份与恢复后仍可查看。已有数据库中的成功轮次调用记录在升级时回填；没有调用记录的旧消息不虚构时间线。
- 成功重新生成时替换当前消息的时间线，旧版本随消息修订保留；失败重新生成保留原回复及原时间线。删除消息时一同清除展示记录。
- 时间线使用原生折叠语义和静态连线，不增加常驻动效；每条消息最多 24 项。工具节点变化纳入消息的更新依赖。
- 此次仅完成源码与 Git 差异审阅；补充了 Rust 回归用例，但未运行测试、构建、启动或真机验收。

## 空间与布局

- Pero：清亮蓝白房间，晴空、云朵、窗外樱花、蓝色窗帘、白色书桌与绿植。
- Nana：紫粉房间，暮色城市、月亮壁灯、电脑桌、耳机、唱片与手柄。
- 当前背景使用 `public/companion/` 内的本地房间插画，按设备时区与时间在日间、晨昏和夜间切换；仅进入或切回房间时刷新。自定义上传背景保持固定，详见 [时段背景说明](ROOM_TIME_VARIANTS.md)。`public/rooms/` 中的旧 SVG 不再是默认房间背景。
- 两个房间使用一致构图和操作位置。其他自定义角色暂用 Pero 的房间背景，角色身份和历史仍独立。
- 首页顶部保留角色切换与菜单，右侧设置聊天、换装、日记的轻量入口。移除原来的日期、大段问候标题与装饰文案，给人物留出更大空间。
- 按手机实测反馈再次收缩人物：窄屏画布宽度上限从 `148vw` 改为 `104vw`，并按可用高度限制；取消房间模式的垂直居中，按人物可见底边约位于画布 98% 的位置锚定输入区上方。`RoomChat` 测量实际输入栏、最近回复和底部安全区占位，人物为提醒条另留空间。低高度窗口沿用相同高度限制，半展开聊天仍保留角色，完整阅读和软键盘场景优先保证消息空间。桌面宽屏保留左右布局。
- 所有本轮陪伴界面的图标和点按装饰使用 SVG，不使用猫爪元素或 emoji 图标。
- 角色点按保留轻微动作反馈，过滤拖动和长按；移除额外的星形粒子，原生动作和互动台词仍走现有模型与 Rust 投影。减少动画偏好继续生效。
- 状态与内心独白收进角色资料；提醒使用独立管理入口和近期提醒条。旧话题入口、抽屉及首页读取链路已移除。

## 对话交互

`rest` 显示悬浮输入栏和可展开的最近一句回复，聊天记录由右侧聊天入口打开，不保留整块面板底色和装饰性脚注。`peek` 展开近期对话，`full` 提供完整阅读空间；展开后可拖动顶部把手或点击展开/收起按钮调整面板。输入、图片附件和展开状态按角色保留在当前页面的显示状态中，切换角色不会混入另一人的草稿。

聊天采用明确区分双方的轻圆角气泡，展开后的背景保持实色可读，不将长文本直接叠在复杂的房间图案上。Pero 的控件使用蓝色，Nana 使用紫粉色，按钮提供轻微按压反馈。悬浮输入框使用薄边与底部强调线，主操作采用深色底，避免大块白色胶囊占据人物前景。

房间中的角色台词另用突出轮廓的说话气泡：不透明白底、圆润边角、角色色双像素描边、轻阴影，以及朝向人物的上方尾巴。名字以角色色标签悬浮在气泡边缘；短台词按内容收缩宽度，长台词最多显示三行，气泡位置为输入区域预留空间。点击仍打开聊天，不改变台词来源或交互逻辑。

长按或点消息旁的菜单可复制、重新生成和删除。删除前明确提示整轮对话及衍生日记的清理范围；实际删除仍由 Rust 负责。失败、停止和中断有独立的显示状态，重新生成复用后端修订规则。

消息按顺序显示，先展示最近 80 条，逐页展开更早的记录。阅读旧消息时暂停自动跟随，提供回到最新消息的按钮。思考内容折叠展示，工具进度转换成简短自然语言，不展示协议 JSON。图片在应用内抽屉预览，Markdown 经 DOMPurify 清理。

移动端按 Visual Viewport 的实际可见高度调整布局，配合安全区处理软键盘；日记和其他抽屉也使用相同测量。桌面宽屏时对话面板靠右，角色保留在房间左侧。交互包含键盘焦点、Escape 收起、抽屉焦点约束和减少动画偏好。

## 日记与其他入口

日记按日期分组，关键词与日期筛选交给 Rust/TDB。支持翻页、查看来源对话、修订和删除；修订提交包含 `expectedRevision`，写入成功后重新读取后端数据。查询失败、修订冲突或存储暂不可用时展示真实错误。

日记工具只有随最终回复成功提交后，Rust 才返回写入数量。首页的日记更新提示使用这一结果；工具中间事件只用于进度展示。

角色选择使用较大的头像、角色简介和已有性格标签。角色资料显示后端投影的心情与内心独白，并提供统一角色管理入口。衣柜继续使用项目已有服装列表及 Rust 的外观偏好保存命令，采用不模糊人物的半屏抽屉，选择服装时保留原生角色的上身效果；宽屏时面板靠右。服装卡片从现有 Pio 贴图中裁出并转正衣服主体区域，展示服装细节缩略而非整张拆件图；缩略按可见范围加载，缺失时使用 SVG 衣架兜底，不额外创建 WebGL 模型实例。这是服装细节预览，完整人物上身效果仍由主角色展示。其他空间保留家庭群聊和小游戏；远程连接改为禁用的“暂未开放”，应用根组件不再挂载旧远程页面，旧模式缓存也不会自动恢复连接。

提醒提升为菜单的独立入口。首页房间模式在输入栏上方展示最近一项与总数，点击打开统一管理抽屉；存在提醒时，角色台词气泡为提醒条预留空间。管理界面支持搜索、新增、修改、取消，以及一次/每天/每周规则和重复截止时间。时间和规则校验、修订冲突检测、到期判断与通知提交均由 Rust 负责，前端只保存编辑草稿并展示结果。异步查询使用身份和版本保护，切换角色或关闭抽屉后不回写旧结果；工具变更提交后、手动操作和投递状态改变时刷新视图。

提醒抽屉提供用户主动开启系统通知和精确提醒权限的入口，展示系统登记模式、阻塞原因与投递错误。安卓说明已接入系统调度以及强制停止限制；其他平台说明应用运行要求。未获精确权限时明确提示可能延迟，读取权限失败时不伪装成已授权。已提交提醒独立保存，不随对话删除；取消通过管理入口或工具完成。

## 家庭群聊

群聊以“大家的小客厅”为视觉线索，淡化已有房间背景，消息保持实色气泡。顶部成员头像与姓名说明参与者和顺序，Pero、Nana 的发言使用各自强调色；头像共用 `CharacterAvatar`，名称只用于展示，不再作为样式或身份依据。输入栏、按压反馈、折叠思考和浮层沿用首页控件。

成员设置移入统一抽屉，使用可键盘操作的上移、下移按钮及开关，不再拦截手机列表的触摸滚动。修改只保存在界面草稿中，点击保存后将 ID、顺序和开关交给既有 `local_group_settings`，消费 Rust 返回的权威成员列表；失败保留草稿，忙碌时禁止重复保存和关闭。关闭未保存的抽屉即放弃草稿。

聊天仍调用原来的 Rust 群聊整轮服务，显示思考、工具进度、失败或中断状态，提供整轮停止及消息复制、删除。最近 80 条按需渲染，向上加载时保留滚动位置，阅读旧消息时暂停跟随，提供回到最新入口。设置或历史读取失败时禁用发送并提供重试，异步回写检查页面生命周期；没有新增前端模型编排。

## 全局界面统一

- `src/styles/companion.css` 定义两位角色的强调色及全局文字、底色、分隔线、圆角和阴影。`src/styles/controls.css` 统一表单、按钮、Element Plus 控件、确认框、提示与浮层。
- 主题由应用根组件维护，挂载到 `body` 的浮层也继承当前角色配色。移除全局暗色变量、旧重置弹窗的彩色发光样式、外部图标字体和装饰字体。
- 首页、设置、角色管理、群聊、小游戏与既有远程页面使用同一套材质；设置等页面共用 `CompanionHeader` / `CompanionPage` 导航。减少粗白边、大圆角、渐变按钮和多层阴影，房间与角色仍为首页视觉主体。
- 设置中心改为分类布局：宽屏左侧导航，窄屏六个分类以两行三列完整呈现。页面头部固定，内容区域独立滚动，缩减表单字号和留白；服务商与 API 协议并排显示。模型连接、回复偏好、个人资料直接调用既有 Rust 设置命令；读取失败时禁止覆盖，保存时避免重复操作，离开前提示尚未保存的表单。
- 服务商、协议和思考强度统一使用 `ChoicePicker` 底部选择弹层，较长列表支持搜索；弹层继承当前角色主题和焦点约束，忙碌时关闭并禁用选择。未在预设内的值仍显示原值，不能因为界面没有预设而误呈现为空。
- 首页名牌、公共页头与抽屉使用原生 SVG 蝴蝶结标记，配合轻切角、细线与局部强调色；角色资料、日记、衣柜和编辑控件沿用相同细节。无需 emoji 图标或外部图标字体。
- API 协议、思考强度和输出/上下文长度读取现有后端配置；未编辑的请求头与高级参数保持原值。模型列表由后端按协议返回，前端只做选择与列表展示。
- 设置中的角色与日记只保留统一入口，不再维护另一份编辑器或记忆列表。角色编辑共用抽屉；保留人设、头像、标签、欢迎语和闲置台词编辑。闲置文本由 Rust 负责转成台词列表。
- 移除已经没有引用的 `ChatArea.vue`、`HistoryOverlay.vue` 和 `role/PromptEditor.vue`，避免继续保留旧聊天界面与编辑器分支。
- 既有远程页面此前完成了视觉统一，现已从应用根组件移除挂载并禁用入口；新版 infOS 协议与远程体系改造仍属后续工作。

Live2D 原生实例在离开首页时隐藏并停放，返回后重新挂载，避免重复注册全局交互。加载失败提供头像与重试入口；切换角色的异步加载检查角色身份和加载版本，外观偏好保存后重新消费 Rust 投影。

## 品牌图标与轻量动效

- 服务商与模型图标对照 infOS 的 `modelBrands.ts` 映射实现，统一由 `src/utils/modelBrands.js` 和 `BrandIcon.vue` 提供。服务商预设、当前连接、模型输入框及查询结果使用本地 SVG；保留 Lobe Icons 的来源记录与 MIT 许可，不依赖远程图标服务或新增包。
- 服务商按实际 API 主机识别，匹配完整域名或其子域名，不把兼容协议当作服务商品牌。修改为未知代理后显示自定义连接，模型仍按 ID 独立识别；支持命名空间和 Anthropic 区域前缀。未知品牌和图片失败时使用通用 SVG，不根据昵称猜测。
- 房间入口返回时按短间隔出现，头像在角色切换时淡入；蝴蝶结、衣柜卡片与发送图标有轻微点按或悬停反馈。设置分类切换、选中标记、附件与消息操作菜单共用短过渡，输入聚焦有强调色反馈。
- 抽屉关闭按钮、遮罩和 Escape 先播放退出过渡，再通知父组件关闭并恢复焦点；忙碌拦截保持有效。菜单跳转、角色切换等由父组件直接卸载的行为不等待退出动画。
- 聊天仅给末尾刚追加的消息播放一次出现动画，不给首次历史加载、翻页或逐字流式更新重复加动画。没有新增粒子、额外 WebGL 画布、emoji 或猫爪装饰。
- 动效以约 120–360ms 的透明度和小幅位移/缩放为主，悬停反馈限定有悬停能力的设备；系统减少动画偏好覆盖页面根节点、浮层和子元素。本轮仅完成源码与差异审阅，未运行测试、编译、构建或启动，实际视觉仍待查看。

## 旧角色头像修复

本机旧角色记录缺失 `avatar` 字段，界面此前将其显示为字母。Rust 的 `normalize_agents` 为缺失该字段的已有 Pero、Nana 补齐项目内默认头像；已有自定义路径和显式空值保留，自定义角色不套用其他角色头像，也不恢复已删除的角色。前端共用 `CharacterAvatar` 展示后端返回值，加载失败使用 SVG 轮廓兜底，并在头像地址变化后重新尝试。

## 验证边界
