# 1.4.3 实装记录

- 本地单聊和家庭群聊增加「工具 · N 项」折叠时间线，按调用顺序展示工具名称、状态和一行结果，不铺开原始参数和整批查询内容。
- 工具事件实时更新到消息；写入操作在回复事务成功提交前显示「待保存」，取消、失败或中断时显示「未保存」。查询成功与写入提交分别表达。
- 时间线随消息持久化，支持重启、备份导出和恢复。已有数据库中的调用记录在升级时回填，旧备份缺少时间线字段时默认空列表。
- 成功重新生成时替换当前时间线并保留消息修订；失败重新生成保留原回复与原时间线。删除消息时一同清除时间线。
- 界面复用主题配色和原生折叠语义，默认收起，每条消息最多 24 项，不增加常驻动画。

版本元数据统一为 `1.4.3`，发布标签为 `v1.4.3`。Android 版本由 Tauri 在 CI 中生成，不手动修改忽略跟踪的生成文件。

本轮仅进行源码、差异和版本元数据审阅。已补充 Rust 回归用例，但未运行测试、ESLint、构建、打包、Tauri 或真机验收；推送发布标签后由现有 GitHub Actions 执行远程打包。
